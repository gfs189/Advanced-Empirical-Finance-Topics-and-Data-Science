Introduction

This report studies minimum-variance portfolio allocation using high-frequency intraday data for the \(N = 30\) constituents of the Dow Jones Industrial Average (DJIA) over the period 2008-2025. The minimum-variance portfolio is the constrained allocation \[ \omega_{MV}(\Sigma) = \arg\min_{\iota'\omega = 1} \omega'\Sigma\,\omega = \frac{\Sigma^{-1}\iota}{\iota'\Sigma^{-1}\iota}, \] whose only input is the covariance matrix \(\Sigma\). We compare two estimators of \(\Sigma\): a high-frequency (HF) estimator built from intraday realized covariances [@andersen1998; @barndorff2011], and a Ledoit-Wolf (LW) shrinkage estimator built from daily close-to-close returns [@ledoit2003]. The central question is whether the additional intraday information in the HF estimator translates into a measurably better out-of-sample portfolio.

The signature plot (Figure 1) shows the characteristic upward bias of the realized variance (RV) estimator at \(\Delta = 1\) minute, where microstructure noise inflates squared log-returns above the true integrated variance (\(IV \neq RV\)) [@andersen1998]. Under a simple i.i.d. noise model, the signal-to-noise ratio at sampling interval \(\Delta_n\) is \[ \pi = \frac{2a^2}{2a^2 + \sigma^2 \Delta_n}, \] where \(a^2\) is the per-interval efficient-price variance and \(\sigma^2\) is the noise variance; as \(\Delta_n\) increases \(\pi \to 1\), so coarser sampling reduces the noise contribution. The curve continues to decline noticeably up to \(\Delta \approx 20\) minutes before flattening at \(\Delta = 30\) minutes, motivating our sampling choice throughout; missing minutes are filled by previous-tick interpolation. We adopt 30-minute sparse sampling over noise-robust alternatives (Two-Scale Realized Variance (TSRV), realized kernels) because the bias is already negligible at this frequency, while we retain useful intraday variation relative to daily returns.

Exercise 2: Daily Realized Covariance

def regularize(Sigma):
    """Add a ridge of size RIDGE_EPS if the minimum eigenvalue is too small."""
    lmin = np.linalg.eigvalsh(Sigma).min()
    if lmin < RIDGE_EPS:
        Sigma = Sigma + (abs(lmin) + RIDGE_EPS) * np.eye(Sigma.shape[0])
    return Sigma

# Compute the 30Ã—30 realized covariance (RC) matrix for every trading day.
# RC_d = Î£_{k=1}^{K} r_k r_k' where r_k is the N-vector of Î”-minute log returns.
RC_dict = {}   # date -> np.ndarray (N, N)

for day, grp in df_wide.groupby(df_wide.index.date):
    sampled = grp[symbols].resample(f"{FREQ}min").last().ffill()
    log_ret = np.log(sampled).diff().dropna(how="all").fillna(0.0)
    R       = log_ret.values    # K Ã— N matrix of intraday log returns
    if R.shape[0] >= 2:  # need at least two intraday returns to form a non-trivial RC
        RC_dict[day] = R.T @ R  # RC_d = sum of outer products r_k r_k'

The realized covariance (RC) estimator \(RC_d = \sum_{k=1}^{K} r_k r_k'\) sums outer products of synchronised 30-minute log-return vectors [@andersen1998; @barndorff2011]. Intraday gaps are filled by previous-tick interpolation; any remaining missing returns are set to zero, a conservative choice that avoids inflating \(RC_d\).

Exercise 3: Covariance Estimators

# Evaluation window: second half of all days covered by RC_dict
all_rc_days = sorted(RC_dict.keys())
midpoint    = len(all_rc_days) // 2
eval_days   = all_rc_days[midpoint:]
rc_idx_map  = {d: i for i, d in enumerate(all_rc_days)}

Sigma_HF   = {}   # High-frequency (HF) random-walk estimator: Sigma_HF_t = RC_{t-1}
Sigma_LW_d = {}   # Ledoit-Wolf (LW) shrinkage on rolling daily returns

for t in eval_days:
    idx = rc_idx_map.get(t)
    if idx is None or idx == 0:
        continue

    # (a) HF random walk: yesterday's realized covariance serves as today's estimate
    t_prev = all_rc_days[idx - 1]
    if t_prev in RC_dict:
        Sigma_HF[t] = regularize(RC_dict[t_prev].copy())

    # (b) LW shrinkage on rolling W_LW daily log returns ending at t-1
    t_ts    = pd.Timestamp(t)
    ret_win = (
        daily_ret[daily_ret.index < t_ts]
        .iloc[-W_LW:][symbols]
        .dropna()
    )
    if len(ret_win) >= MIN_OBS:
        lw            = LedoitWolf(assume_centered=False).fit(ret_win.values)
        Sigma_LW_d[t] = lw.covariance_
eval_start = pd.Timestamp(eval_days[0]).strftime("%B %d, %Y")
eval_end   = pd.Timestamp(eval_days[-1]).strftime("%B %d, %Y")

The evaluation window runs from January 17, 2017 to November 14, 2025. (a) HF random walk: \(\hat\Sigma_t^{HF} = RC_{t-1}\) uses yesterday’s realized covariance as today’s forecast. This implicitly assumes that the covariance matrix follows a random walk: \(\Sigma_t = \Sigma_{t-1} + \varepsilon_t\), so that the best one-step-ahead predictor is the most recent observation. Equivalently, it treats the covariance as constant within each day and allows it to change arbitrarily between days, with no mean reversion or smoothing. (b) LW on daily returns: \(W = 252\) days gives \(T/N \approx 8.4\), ensuring a full-rank sample covariance; @ledoit2003 shrinkage toward a scaled identity stabilises the precision matrix for portfolio inversion.

Exercise 4: Minimum-Variance Portfolio Weights

def min_var_weights(Sigma):
    """Closed-form MV weights: w* = Sigma^{-1} iota / (iota' Sigma^{-1} iota)."""
    N    = Sigma.shape[0]
    iota = np.ones(N)
    try:
        Si_iota = np.linalg.solve(Sigma, iota)
    except np.linalg.LinAlgError:
        Si_iota = np.linalg.pinv(Sigma) @ iota
    denom = float(iota @ Si_iota)
    return Si_iota / denom if abs(denom) > RIDGE_EPS else iota / N

common_days = sorted(set(Sigma_HF) & set(Sigma_LW_d))

omega_HF = {t: min_var_weights(Sigma_HF[t])   for t in common_days}
omega_LW = {t: min_var_weights(Sigma_LW_d[t]) for t in common_days}

def avg_turnover(omega_dict):
    """Average daily turnover: (1/T) Î£_t Î£_i |Ï‰_{i,t} âˆ’ Ï‰_{i,t-1}|."""
    days = sorted(omega_dict)
    tos  = [np.abs(omega_dict[days[i]] - omega_dict[days[i - 1]]).sum()
            for i in range(1, len(days))]
    return float(np.mean(tos))

Exercise 5: Out-of-Sample Portfolio Evaluation

# On day t, apply weights formed from data up to t-1 to the return realised on day t+1.
eval_sorted = sorted(common_days)
ret_rows    = []

for i, t in enumerate(eval_sorted[:-1]):
    t_next = pd.Timestamp(eval_sorted[i + 1])
    if t_next not in daily_ret.index:
        continue
    r_next = daily_ret.loc[t_next, symbols].values
    if np.isnan(r_next).all():
        continue
    r_next = np.nan_to_num(r_next, nan=0.0)   # missing returns treated as zero

    ret_rows.append({
        "date":  t_next,
        "r_hf":  float(omega_HF[t] @ r_next),
        "r_lw":  float(omega_LW[t] @ r_next),
        "r_ew":  float(np.ones(N_stocks) / N_stocks @ r_next),
    })

portfolio_ret = pd.DataFrame(ret_rows).set_index("date").dropna()
def perf(col):
    r   = portfolio_ret[col].dropna().values
    vol = r.std()  * np.sqrt(ANNUALIZE)
    sr  = r.mean() / r.std() * np.sqrt(ANNUALIZE)
    return round(vol, 4), round(sr, 3)

vol_hf, sr_hf = perf("r_hf")
vol_lw, sr_lw = perf("r_lw")
vol_ew, sr_ew = perf("r_ew")

performance_summary = pd.DataFrame({

Equal-weighted achieves the highest annualised Sharpe ratio (0.763); HF (RC, t-1) produces the lowest (0.572). The HF estimator does not outperform LW on Sharpe ratio (0.572 vs. 0.674).

The random-walk estimator uses only a single day per forecast; in the post-2016 window, LW’s smoothing advantage dominates, producing more stable weights and a higher Sharpe ratio. HF covariance information adds most value when \(N \gg 30\) and the true covariance shifts rapidly [@ledoit2004]; with only 30 DJIA stocks, LW already captures the dominant structure.

More broadly, these results illustrate a recurring finding in the portfolio choice literature: statistical sophistication in covariance or return estimation does not automatically translate into out-of-sample economic gains. The equal-weighted benchmark achieves the highest Sharpe ratio here, consistent with the observation that estimation error in large covariance matrices can amplify, rather than reduce, portfolio risk. Estimators that exploit additional information, such as intraday returns, shrinkage targets, or factor structures, tend to deliver meaningful improvements when the signal-to-noise ratio is high: either the universe is large enough that noise in the sample covariance is severe, or the true covariance structure is time-varying rapidly enough that high-frequency updates are valuable. With \(N = 30\) liquid, well-studied blue-chip stocks over a relatively calm post-2016 sample, neither condition is strongly met, so the naive \(1/N\) rule proves difficult to beat [@ledoit2004].

Conclusion

This report compared two covariance estimators for minimum-variance portfolio allocation across 30 DJIA stocks. The HF random-walk estimator reacts to intraday information but, with only \({\sim}13\) intraday returns per day, produces noisy forecasts that drive excessive turnover and the lowest out-of-sample Sharpe ratio. The LW estimator, despite relying only on daily returns, achieves lower portfolio volatility and a higher Sharpe ratio by smoothing out day-to-day noise. The binding constraint is the signal-to-noise ratio: with \(N=30\) liquid blue-chip stocks and a relatively calm post-2016 evaluation window, neither estimator generates enough precision to overcome the equally weighted benchmark. Noise-robust HF estimators such as realized kernels, or evaluations on larger and more heterogeneous universes, are natural next steps.
